# Predome patent evidence

This directory contains a traceable, deliberately small patent pilot. The catalogue
is an evidence browser, not a clinically validated prediction dataset.

`catalog.json` is generated by `python scripts/ingest_patents.py build`. It has two
real downloaded publications and per-page OCR provenance. `sources/` preserves the
original acquisition manifest and structured observations. `raw/`, `ocr/`, and
`receipts/` are excluded from Git; copy them as deployment artifacts when needed.
The public catalogue links to the original PDF and its 1-based PDF page number.
Printed patent page numbers differ from PDF page numbers.

## Reproduction

From `apps/predome`, using Python 3.10+ with a working system CA trust store:

```sh
python scripts/ingest_patents.py download --publication WO2019125938A1
python scripts/ingest_patents.py download --publication WO2020240467A1
python scripts/ingest_patents.py ocr --dpi 150
python scripts/ingest_patents.py build
python -m unittest discover -s tests -p test_patent_evidence.py -v
```

OCR requires `pdftoppm` and `tesseract` with English language data. It runs one page
at a time, uses a single Tesseract thread, strips API credentials from subprocess
environments, checks hashes before resuming, and removes temporary page images.
OCR executes offline. It must not run inside a public API request.

## Authorized source connectors

The offline CLI reads `EPO_OPS_KEY` / `EPO_OPS_SECRET` for EPO OAuth and
`USPTO_ODP_API_KEY` for USPTO ODP. Never store actual keys in this directory.

```sh
python scripts/ingest_patents.py epo --publication WO2019125938A1 --section family
python scripts/ingest_patents.py epo --query 'ti="incretin analogs"'
python scripts/ingest_patents.py odp --query 'datopotamab'
python scripts/ingest_patents.py odp --application 16123456
```

The last command is an example of an eight-digit application-number lookup, not a
claim that this application belongs to either pilot drug. Authorized calls were
not tested with live credentials during the pilot; the public API reports that
state. CLI receipts preserve source URLs, retrieval time, response hash and raw
XML/JSON. EPO family responses can enrich the catalogue without inventing family
membership. Missing full text or image coverage remains a source limitation.

Primary interface references:

- [EPO OPS reference guide](https://link.epo.org/web/searching-for-patents/data/en-ops-v3.2-documentation-version-1.3.20.pdf)
- [USPTO PFW search](https://data.uspto.gov/apis/patent-file-wrapper/search)
- [USPTO PFW documents](https://data.uspto.gov/apis/patent-file-wrapper/documents)
- [USPTO PatentsView migration notice](https://content.govdelivery.com/accounts/USPTO/bulletins/40e8c67)
- [WIPO PATENTSCOPE terms](https://www.wipo.int/en/web/patentscope/data/terms_patentscope)

PATENTSCOPE website automation is not implemented. Its free website prohibits
automated queries, scraping and bulk acquisition; use licensed WIPO data services
if an automated WIPO connector is commissioned.

## Evidence and temporal gates

`read_catalog()` and `get_patent()` are local, read-only functions. They perform no
network requests. `freeze_evidence_pack(drug, cutoff)` includes only evidence that
passes explicit drug identity, public availability, complete extraction and
source-review gates. Dato-DXd has an explicit `two_agent_visual_source_check`
research gate: the two AI roles separately checked original patent pages 87, 88,
93 and 94, official NCI development-code aliases, and the ClinicalTrials.gov
intervention and study identifiers. The receipt is
`sources/WO2020240467A1.identity-review.json`. It binds the original PDF, selected
experiment-card content, and source/mapping evidence by SHA-256. Changed numeric
content or mapping fails the gate. The roles share a base model; their errors may
be correlated. `human_review_count` is zero and clinical prediction validation is
false. This is permission to use traceable research evidence, not clinical review.

The Dato identity chain is ADC (1) = DS-1062a (PDF p. 87, [0419]), the trial
NCT03401385 (PDF p. 88, [0425]), and Study DS1062-A-J101 (PDF p. 93, Table 2),
cross-checked against official canonical-name and trial records. ADC (2) and
unreviewed examples are excluded. Full sequence alignment to a regulatory INN
record has not been performed; the explicit codes and trial identifiers, rather
than a guessed structural similarity, support this research identity mapping.

Retatrutide has a new, separate AI structure-review record:
`sources/WO2019125938A1.identity-review.json` selects the versioned
`WO2019125938A1.retatrutide-ex12-v1.json` card. Original patent PDF22/37 identifies
Example12 as SEQ17. Its complete modified peptide features agree with the WHO
proposed INN definition at PDF123/printed1051, including Aib2/20, alpha-methyl-L-Leu13,
Lys17 N6 conjugation through one AEEA and L-gamma-Glu to a C20 diacid, free carboxyl
groups and the Ser39 amide. The exact-feature comparison does not automatically
read chemical drawings or establish formulation/batch equivalence. Two same-base
AI roles checked the originals; human review remains zero.

WHO's [publication notice](https://cdn.who.int/media/docs/default-source/international-nonproprietary-names-(inn)/pl128.pdf#page=2)
dates publication to **2023-01-20**, although the volume is labelled 2022. Review
completed at **2026-10-26T16:55:51.222863+00:00** (2026-10-27 in Asia/Taipei).
Earlier cutoffs remain blocked. This new research input does not amend any prior
prediction, clinical evidence pack or timestamp proof. Only the source-verified
name `retatrutide` is enabled; unverified development-code aliases are not inferred.

The original Example1/SEQ7 mouse card remains unchanged in its old curated file
and is retained as `excluded_experiment_cards` in the catalogue. It differs at
residues20/28/29 and has two AEEA units. It must not enter a retatrutide packet.

The public date, data cutoff, priority date and retrieval date are separate facts.
Date-only publication availability is conservatively interpreted as the end of
that UTC day. A later mapping source cannot be imported into an earlier forecast.
Current family and legal-status data and unreviewed candidate sections are excluded
from the frozen scientific packet. The catalogue and packet use versioned local
canonical JSON hashing (NFC strings, sorted keys, compact UTF-8, no NaN), not an
external notarization or a claim of RFC 8785 conformance.

The current NCI/ClinicalTrials.gov pages are conservatively dated to their actual
retrieval timestamps (2026-10-22). The AI review completed at
2026-10-22T15:51:33.359677+00:00. A newly frozen Dato experiment must have a cutoff
after that time; older frozen runs remain immutable and cannot receive this data
retroactively. Original source snapshots and rendered page checks are stored in
`receipts/review/` and should accompany the deployment archive for audit.

The two structured experiment cards demonstrate actual extractable content:

- WO2020240467A1, PDF p. 93, Example 7/Table 2: investigator-assessed unconfirmed
  phase 1 ORR. The absence of a randomized comparator and the response-evaluable
  denominator are explicit. PDF p. 87 contains the DS-1062a development code.
- WO2019125938A1, PDF29/Table3, Example12/SEQ17: relative cAMP EC50 in separately
  receptor-overexpressing HEK-293 cells under 0.25%FBS/0.05%BSA. GcgR, GIPR and
  GLP-1R values are 6.61/2.24/12.4nM; SEM 0.512/0.303/1.41nM, reported n=6 each.
  PDF30 supplies concentration ranges. Biological versus technical independence
  and raw curves remain unknown. Native-control EC50 values lie below the printed
  native-control concentration range; the unexplained source relationship and
  original units are retained. Table4 casein values and Table2 binding Ki are not
  mixed into this card. The archived OCR's `141` is preserved; the selected card
  uses the original-page SEM `1.41` with an explicit discrepancy record.
- Excluded WO2019125938A1 PDF34/Table7: Example1 analog mouse measurements remain
  visible for audit and are not assigned to retatrutide.

These records do not establish clinical efficacy, patent freedom to operate, a
prospective prediction, or improvement in model accuracy.

## Original-evidence deployment

The new structure review names original source files, selected page previews and
the AI observation record under `receipts/review/retatrutide-20261027/`. They remain
outside Git. A separate, SHA-256-pinned review-originals archive accompanies the
commit-pinned catalogue and selected-card metadata. `install_patent_review_bundle.py`
stages only that exact referenced file set into a new release, checks every digest,
and rejects links, unexpected members, oversized archives and conflicting existing
bytes. It never acquires data, reads a patient/runtime database or grants a review.
The cumulative deployer requires this archive before activating the new metadata;
its release manifest includes the staged originals. Rollback remains code-only.

Provider input projection now preserves explicitly supplied structured review
scope, including AI basis, human count, receipt hash and research/validation flags.
Absent fields stay absent and explicit null stays unknown. These disclosures do
not grant eligibility. A fresh execution of an older packet that already carried
previously omitted metadata has a new actual input hash and requires a new run;
it cannot replace the original request, forecast or timestamp.
