# Predome Editorial 01

2026-10-21，参考 Anthropic 首页的暖白底色、编辑式排版、细分隔线与克制留白。保留 Predome 名称及研究信息，未使用 Anthropic 字体文件、图片、标识或宣传内容。

## 适用范围

首页、预测与实际记录、试验详情、模型分析、提交试验共用 `static/design-system.css`；页面以 `design-system` 类显式启用。历史研究工作台的独立布局保持原样。已有页面 CSS 负责结构和交互，共享文件负责视觉令牌和组件表现；新样式应添加到共享层，不继续在各页面复制颜色。

## 视觉约定

- 暖白 `#f7f6f2` 作为画布，纸白 `#fffefa` 作为内容面，深墨 `#24231f` 作为主要文字。
- 铜棕 `#9a4f36` 用于强调与焦点。概率使用中性色，不用装饰色暗示确定获益。
- 正向与负向状态分别保留绿、红，并同时显示文字。拒答和未核验必须保留明确标签。
- 标题与主要数字使用系统衬线字体；导航、表单与说明使用系统无衬线字体。无外部字体请求。
- 主要面板 5px 圆角，细边线、无装饰阴影。表格与时间轴允许内部横向滚动，页面整体不得溢出。
- 操作按钮至少42px；表单输入至少42px。键盘焦点显式描边；遵守减少动态效果偏好。
- 1100px 以下导航独占一行；700px 以下主体单列，筛选器双列，试验比较在局部容器横向浏览。
- 深色模式使用同一组语义令牌，暖灰背景与浅色文字；主题偏好沿用现有持久化逻辑。
