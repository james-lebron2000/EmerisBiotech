# Predome 1.1.8 产品交付与持续迭代规范

本次目标是在已部署的 1.0 日历上补齐用户输入、不可覆盖预测账本、实际结果独立核验和性能分析。验收依据为同目录 product-target.txt 原文及 requirements-audit.json；原文在第十二节中途截断，缺失部分不作推断。

## 用户如何使用

1. 首页 `/`：默认查看未来 90 天读出窗口。Calendar、Timeline、Table 切换；按公司、适应症、阶段、药物类型及分子靶点、模型和概率筛选。半年度窗口表示官方计划区间，不代表某个确定公布日。
2. `/trial/NCT…`：查看输入、终点、人群、比较、不同模型判断、证据、版本及结果。模型概率是未经校准的研究估计，模型分歧不是置信区间。
3. `/track-record`：已锁定、已核验和历史回放分开。历史回放在结果公布后执行，不能计入前瞻命中率。
4. `/predict`：注册登录后从 NCT、PDF/DOCX 或手动字段建立试验档案。字段保留来源、缺失状态和用户确认。可运行证据审查或明确假设的统计情景；LLM 实时概率依赖管理员配置模型服务，未配置时如实显示 unavailable。
5. `/reviews`：来源抓取只创建候选。具备审核权限的账号关联具体主要终点、提取结果，另一位独立审核员核对并批准。预测所有者及提交者不能批准自己的结果。
6. `/analytics`：按模型、版本、回顾/前瞻查看校准、分布、累积与滚动指标、六类分组和同病例基线。低于 20 条或 5 个资产组不展示性能结论；此阈值不是验证完成的统计保证。

## 输入与输出契约

输入包含研究编号、药物、适应症、机制、设计、人群、治疗臂、主要终点、随访、样本量和统计规则。缺失字段保留为空；文档提取须人工确认；用户修改公开字段后来源退回 user。

输出包含针对指定 endpoint / population / comparison / success_definition 的独立模型概率或拒答、依据引用、风险、假设、未知项、输入与请求哈希、模型版本、流程版本和时间。统计功效场景不等于药物临床成功概率；未校准的 LLM 估计不等于已验证模型。

原始冻结档案导入账本时保留 original generated/locked/cutoff 和原 SHA，另外新增 imported_at。导入时间不冒充预测时间；新封装 SHA 不替代原始 SHA。服务器时间尚无独立第三方时间戳证明。

## 可重复使用的开发提示词 v1.1.8

在现有 Predome 工程上迭代。先读 product-target.txt、requirements-audit.json 与最近部署回执。逐条维护输入、预测、锁定、结果来源、独立审核、评价六个环节，不以新增页面代替功能闭环。

优先完成可验证的真实用户路径：公开 NCT 导入 → 字段确认 → 真实可用引擎 → 私有报告 → 用户明确选择公开 → 不可覆盖快照 → 实际主要终点来源 → 独立审核 → 评价。没有凭据、没有结果、来源冲突、无法判断的情况必须保留明确状态，不生成替代概率或阴性标签。

不改写历史冻结数据，不将回放或测试记录混入生产。每个预测目标独立核验，同一试验多个终点不能互相替代；不同版本采用预先规定的首次公开锁定规则，不能事后选最好结果。先用隔离数据库和浏览器验证，再备份与部署；部署后复核版本、源哈希、公开页面、后台任务和原服务存活。

每轮输出具体改动、测试回执、部署状态和剩余缺口。没有证据证明的功能不得写“已验证”。模型更新先以新版本并行记录，达到预设的独立验证条件后再选择上线，不自动覆盖旧模型和旧预测。

## 模型提示词迭代与自进化边界

在线 `prediction_service.SYSTEM_PROMPT` 要求模型仅使用本次提供的证据、逐字绑定成功定义、引用已提供的 evidence_id，不利用未提供的试验结局，不将缺少公告判为失败，不发明置信区间。每次请求保存提示词 SHA 和请求 SHA。提供商预训练记忆仍无法排除，因此历史回放只能作开发分析。

目前“迭代”是新增输入版本、模型输出、结果审核和评价记录。尚未实现自动权重学习、自动校准上线或模型自主晋升。下一版应在项目/药物层分组、时间外验证、独立保留集与回滚规则齐备后再实现自动晋升。

## 运维与尚未关闭的配置门槛

每日公共来源任务使用独立 systemd timer，09:10 台北时间起随机延迟最多 5 分钟，访问 ClinicalTrials.gov、Europe PMC / PubMed 及配置的官方公司公告与指导资料；最多追踪 30 个公开 NCT 并取 20 个 sponsor discovery 候选。官方来源限配置的域名、4 个新闻索引、最多 16 个文档，未承诺全市场或全历史覆盖。私有 NCT 不送外部。来源失败、结果缺失和不匹配只入待审核状态，不更新绩效。

上线安装前 `scheduled_read_only=false`；安装并启用后才能设置为 true。系统公开展示最近运行状态、来源数和失败数，未执行不能宣称同步完成。

实时 LLM 需要 `DEEPSEEK_API_KEY` 与 `EMERIS_ENABLE_USER_LLM=true`；配置路径由管理员提供，不在聊天、仓库或浏览器输出密钥。独立审核需要两个已注册且确认归属的账号，配置 `EMERIS_REVIEWERS`，不得预留未注册名字。账号含不可覆盖账本时自动删除返回 409，明确没有删除；需管理员处理保留和删除要求，当前不提供该类记录的自助删除。

发布脚本保留旧 release、完整数据库备份、完整性校验和失败自动回滚。SQLite 新增表为加法迁移；回滚代码不抹去已写入记录。预测概率仍未经临床效用验证，本产品服务研发证据审查。

## 1.1.1 日历信息更新验收补充

药物类型与靶点来自逐项绑定试验编号的可追溯资料。联合方案只标注所索引药物，不将一种药物的类型或靶点代表整个方案。原始登记干预类型另行保留。

公开公告采集只生成候选；真实原始 HTML/PDF 字节独立保存并校验 SHA-256。候选按来源与 NCT 去重，同一 PDF 涉及多个试验时均保留。受限页面返回错误时展示部分覆盖，不自动把旧资料标为刚核实。

读出时间提议要求引用来源原文、精确试验身份及时间精度。另一审核员批准后只替换展示日历；原始预测概率、证据截止、冻结时间、原窗口继续保留。研究完成日期与结果公告日期分开。来源、实际疗效、日历更新各自分页并审核；没有独立批准不产生实际疗效标签。

## 1.1.2 相似登记与结果抽取验收补充

详情页第 5 节提供用户主动触发的当前登记关键词查询。每项显示设计、终点、观察时间、入组数及 ACTUAL/ESTIMATED 类型、来源更新日期、查询时间和响应哈希。当前匹配是证据整理线索，不是历史时点模型输入或疗效可迁移性证明；不写入已冻结预测。

定期采集发现登记结果后，从已校验原始字节抽取 PRIMARY 终点，逐一保留各项统计分析及其组别、方法、效应、区间和原始 P 值。按 NCT 配对公开锁定快照；同一 NCT 不等于终点、人群或分析匹配。保存流程版本与建议哈希，进入审核工作台，不自动创建成败标签或绩效。私有预测不参与配对。

审核员从建议选择快照时，只填入快照编号；预测目标作为只读对照，实际终点、人群、比较、结果标签与首次读出时间仍须据来源核实。不将名义 P 值、P<0.05、次要分析或缺少公告视为主要终点成功/失败。不把 P 值不等式改写为精确值。大规模建议受到数量和字节预算限制，明确显示未展开总数并保留原始来源供复核。

人工录入双侧置信区间时，必须同时填写来源中的置信水平、下限和上限；不提供默认 95%。99% 记录为 level=0.99；不完整、置信水平越界或上下限反序的记录拒绝保存。来源中单侧区间等未适配的结构仍保留原文待核实，不补造双侧数值。


## 1.1.3 分组资料与来源缓存验收补充

公开预测摘要与公开分组资料分别取得用户确认，默认均不选择。分组资料只能从该次报告已保存的结构化输入提取；不得在锁定时偷偷读取或展示私有方案正文。锁定前展示将公开的具体字段，用户自报的治疗领域和申办方类别标注为用户分类。未授权的字段在公开评估中保留 unknown，不用试验编号冒充独立药物资产。新确认写入新快照，旧快照的字节、哈希和授权范围保持不变。

官方 PDF 每轮仍须访问真实来源。只有来源 URL、原始字节哈希及解析器版本全部一致且归档完整性通过时，才能复用已验证的文本抽取；页面检查时间与原文发布日期、首次抽取时间分开。缓存损坏、来源失败或解析超时不能转换为疗效结论。交付必须附隔离用户流程测试、缓存失效与损坏测试、浏览器授权流程测试及公网部署回执。


## 1.1.4 前瞻基线与目标身份验收补充

每项公开预测可关联独立、不可覆盖的基线登记。首个基线为固定 50% 的无信息参照，输入特征为空，不从真实结果估计参数，不代表适应症的历史成功率。基线与完整的 endpoint / population / comparison / success_definition、原快照哈希和政策版本绑定。

基线登记时间使用真实服务器时间。已有预测只能新增当前时间登记，不能改写旧预测或回填锁定日期；新公开预测与基线登记在同一事务完成。无信息基线的信息边界对齐原预测截止日，实际没有读取任何特征；这不改变基线生成与登记的真实时间。只有预测和基线都在实际结果首次公布前锁定，且目标、哈希、政策完整性通过，才纳入前瞻基线比较。

基线缺失、锁定太晚或其他资格问题必须明确展示。模型自身的可评分记录不会因没有基线而被删除；比较表另行列出所有方法共享的交集、未匹配数量与原因。固定 50% 是中性概率参照，不用它声称已建立历史基础率模型。相同试验名称或终点缩写不足以合并记录，不同人群、对照或成功定义须保持独立。

验收需覆盖新公开锁定、旧快照迁移的时间与字节不变、私有隔离、事后锁定排除、篡改拒绝、完整目标身份、同病例分母，以及没有真实结果时不生成表现数值。生产环境不得为展示基线评分而加入测试结局。


## 1.1.5 多模型汇总与可解释报告验收补充

新报告使用预先固定的等权双模型规则，每个成员权重 50%。只在两个指定成员都对本次相同输入、完整目标与证据截止输出有效概率、提示词及请求哈希校验通过时计算描述性汇总。一个模型拒答、失败、未启用或绑定不一致时，集成概率保持为空；单模型报告不补齐第二个概率。条件统计情景不参与集成。

分别展示单模型概率、汇总概率与最大最小差。模型分歧不是置信区间，等权平均未经校准，也没有证据证明比单模型更准确；不纳入当前单模型绩效或增加评估分母。报告保留策略版本及哈希、成员权重与原始输出哈希、输入和目标哈希、数据截止及真实生成时间。

公开锁定前明确说明将公开的摘要范围；私有方案、原始证据文本及模型推理不随集成摘要公开。锁定保存完整报告，公开接口只按字段白名单返回摘要。旧报告和旧冻结预测不追补集成，不重写概率、时间或哈希。新模型策略必须使用新的版本和新的报告，不根据已公布结果反向挑选成员或权重。未来策略升级须保留旧策略校验器，并按已保存的 policy_version 路由；不能直接替换常量后让旧草稿无法锁定。当前实现仅支持已发布的 equal-weight-two-model.v1。

本轮验收必须区分三种证据：隔离环境中的模拟模型响应验证计算和流程；真实公网只读验证上线与旧档案完整性；真实外部模型调用需配置服务后另行验证。测试概率不得作为生产预测。完整输出及真实结果对照仍以正式公开锁定记录为准。


## 1.1.6 官方结果核验与可追溯摘录验收补充

官方公告候选可以分别提交日历更新或实际临床结果。结果提交必须从保存的正文选取连续原文，重新校验原始 HTML/PDF 字节、来源哈希和试验身份；只有药名或相近编号不能关联结果。候选提取文本与原始字节不一致时拒绝。实际终点、人群、比较、首次结果读出日期、标签及统计值均须据来源填写，不从预测目标或模型结论自动填入。

来源公告日期与首次结果读出日期分开。原文元数据有日期时必须一致；没有时要求提交者明确填写，不把旧指导材料日期自动当作新结果公告日期。未来日期、晚于抓取日期的公告日期和晚于公告日期的首次读出日期均拒绝。原文摘录仅证明来源中存在这段文字；它是否支持指定主要终点仍须独立审核，提交者及预测所有者不能批准。未审核、拒绝或不能判断的结果不进入绩效。

独立批准后，公开实际结果展示经过校验的短摘录、摘录哈希和公告日期依据；不公开未选中的全文、内部候选字段或审核人员私有信息。没有摘录的旧结果保持原样，不补造证据。

来源失败展示实际 HTTP 状态、检查时间和有限错误类型；不展示响应正文、Cookie 或异常中的敏感信息。HTTP 403 是来源访问被拒绝，不等于试验失败。旧任务没有的诊断值标记未记录，不根据新代码回填历史日志。

新增官方跟踪来源必须以额外配置接入，绑定既有 NCT、试验名、药物、允许域名和本地原始文件哈希。原冻结证据、概率、窗口及时间保持不变。第一三共 AVANZAR FY2026Q1 材料为额外读出计划来源，不是临床疗效结果，也不代表其他试验的来源问题已解决。

验收覆盖原始字节与结构化文本篡改、试验身份与日期边界、来源失败分类、匿名与非审核员权限、独立审核后公开及评分、旧接口兼容、手机与深色展示。上线后实际执行一次公共采集并核对终态；不得把隔离测试中的审批、概率和结局写入生产。


## 1.1.7 真实官方 PDF 解析验收补充

新来源必须用真实原始文件在生产同等解析限制下验收，不能只靠模拟 HTTP 或合成一页 PDF 测试。第一三共公开材料带有加密标记，但无需密码即可打开，并设置了允许提取文本与图形的权限；官方解析器现仅在空密码打开成功且该权限明确存在时读取这类文件。需要非空密码或未授予该权限的加密文件仍拒绝；不尝试密码、不移除限制、不重写原文件。

解析器版本升级为 official-document-v3，旧缓存须重新解析后才能供新版本使用，旧来源候选保留原始字节和原时间。128 MiB 子进程地址空间、12 秒 CPU、60 秒墙钟、200 页及文本长度上限保持不变。公开错误将文档解析失败、解析超时与 HTTP 访问失败分开显示，不把任一种失败转换为临床结局。追加真实官方 PDF、需密码和禁止提取 PDF 的回归，部署后再次运行真实采集。


## 1.1.8 可信度修复与验收契约

每次迭代先核查真实交互与数据来源绑定，发现缺陷后以能复现该缺陷的测试证明修复。不能用测试数量或页面美观替代临床预测能力验证。

- 生成时间读取审核通过、完整性校验通过的原始模型运行完成时间；锁定时间单独展示。显示实际返回模型版本，不用锁定时间冒充生成时间，不改写既有快照。
- 前瞻覆盖率分母包含符合时间、目标、独立核验及首次公开锁定规则的 predicted / abstain / failed / unavailable 请求。拒答、失败、不可用分别报告，不赋予虚构概率；Brier、校准和同病例基线仅使用数值预测。未锁定草稿不在该分母中。后续有数值版本不能替换首次公开拒答以提高覆盖率。
- 日历时间更新的提案与批准必须重新验证留存原文、摘录和精确试验身份。可变候选正文与标记不是原始证据。通用人工结果提交不得声明机器核验专属字段。
- 新 NCT、新文档或清空研究时，清除旧成功定义、证据、比较、情景及报告关联；过期异步响应不得注入新研究。相似登记凭据及父版本访问在占用模型额度前验证。
- DOCX 按段落及表格结构恢复文字，不因加粗等格式 run 边界截断终点。提取值仍需用户确认。
- 表格可选择少量试验并排比较；各目标的成功定义、概率、版本和窗口独立展示，不跨目标平均，不把分歧包装为置信区间。
