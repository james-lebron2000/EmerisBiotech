# 原文位置从证据卡到模型与公开引用

本轮修复已有定位字段在传递中丢失的问题。真实赛季目录中，INAVO121 所用的间接 INAVO120 prior 卡记录了 `page_references=[59]`，MEVPRO-1 protocol 卡记录了章节位置。旧 Provider 投影不发送这两个字段，公开引用投影也没有保留它们。用户虽然能打开原始文件，却无法从引用条目找到已记录的位置。

新代码保留来源明确提供的位置和文档版本。它不会补出未经审核的 SAP 参数、自动读取原件、替换模型输出或授予科学资格。INAVO120 仍属于另一项研究；位置展示不使它成为 INAVO121 的主研究统计方案。

## 三个可选字段

标准库模块 `arena_evidence_locations.py` 拥有 `validate_locations()`，由准备工具、模型适配器和公开报告复用。

| 字段 | 合同 | 含义 |
|---|---|---|
| `page_references` | `null` 或最多 100 个不同的整数，每项 1–10000；不接受布尔值或数字字符串 | 原样记录的页码。编号可能是 PDF 页或印刷页，不能统一推断为一基 PDF 页号 |
| `source_anchor` | `null` 或最多 1000 字符的非空字符串，无控制字符 | 已记录的章节、表格、段落或登记字段位置 |
| `document_version` | `null` 或最多 200 字符的非空字符串，无控制字符 | 操作者明确提供的版本，不从标题、文件名、URL 或日期推断 |

字段缺失、显式 `null` 和空页码列表分别保留；字符串不自动改写。额外字段不会被此合同带入下游。原有 `page`、明确命名的 `pdf_page_1_based` 及正文含义不变。通过结构检查不证明定位准确、适用 amendment、来源公开时间或摘录正确。

## 新模型调用

Provider 升至 `arena-providers-1.3.0`，受控 Agent 升至 `arena-agents-1.2.0`。新调用把这三个字段与原证据 ID、文字、URL、来源 SHA 和可用时间一起发送。非法定位在请求前被拒绝，不产生自动修复、重试或额外调用；没有新字段的输入保持原投影和 Prompt 内容。

Agent 的证据审查与预测阶段使用相同的检查后数据。新执行契约同时绑定 Provider、诊断辅助模块与定位辅助模块的实际文件哈希；改变辅助模块也会使既有登记契约不再匹配当前执行实现。需要单独的新运行，不修改旧输入或重新执行失败槽。

`prepare_arena_season.py` 保留操作者提供的 `document_version`，并在离线准备时检查页码、章节和版本。该工具不自动创建来源审核票、不新增文档内容、不注册任务，也不调用模型。新取得的 Protocol／SAP／OCR 仍须单独核对后进入新的截止时间和输入版本。

## 公开页面与下载

公开 record 为 `arena-clinical-public-1.4`。所选模型的 `Rationale & sources` 展示已有页码、章节和版本；未记录时保留空状态，不借用全局或其他模型的引用。原文与快照链接保持原来源，不生成猜测的 `#page=` 链接。

Clinical Brief HTML／Markdown 和 Campaign 报告展示同一公开定位元数据。公开投影不附带本地 `source_path`、Prompt、内部审核身份或任意原始字典；格式不合规或包含已识别凭据样式的位置不发布。限定模式过滤不是普遍的敏感信息检测，来源仍需审核。

位置称为 **Recorded pages / Recorded section / Document version**。旧冻结包有位置字段，并不证明旧版模型实际收到这些旁路字段，也不证明模型看过完整 PDF。历史输出不因新的展示代码而获得这种证明。

## 旧记录与结果解释

新导出使用 1.4；已生成的旧公开记录、ZIP、哈希和时间凭证不重写。历史 1.0–1.3 Campaign 包继续按各自版本只读核验，不能冒充新导出或取得新时间凭证。1.3 与 1.4 使用返回判断的一致率分母；1.2 及以前的旧分母仅用于核验原档，不混用两种统计语义。

来源位置不影响预测方向、概率、校准状态、结果接纳、正确／错误标记或排名。未公布结果继续等待；缺失校准继续 N/A。位置可追溯、OCR 完成、请求成功和临床预测有效性是不同的验收问题。

## 验收范围

测试覆盖实际准备工具、模型协议请求体、Agent 两阶段及契约预检、临时账本的公开 API、Brief／Campaign、旧包核验和桌面／移动引用展开。受控模型和浏览器样例是工程 fixture，不作为真实临床预测展示。真实目录元数据仅检查位置能否保留，不改变目录、原件或旧模型记录。

[真实目录投影记录](records/evidence-location-projection-20261027.json)检查全部 27 张卡片的定位格式，并对上述两个真实元数据样例核对 Provider、Agent、Public 三个实际投影。缺失的文档版本仍未补出；这次纯投影不刷新旧赛季筛选、不创建合格新任务、不读取原 PDF，也不调用模型。桌面与移动端的[界面预览](images/evidence-locations-20261027/README.md)使用明确标注的 synthetic／offline fixture，只用于检查实际页面的展示与排版。
