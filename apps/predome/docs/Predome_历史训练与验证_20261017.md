# Predome Agent System：历史训练与时间留出评测

版本：2026-10-17。状态：探索性研发评测；没有临床预测验证，也没有前瞻命中率。

## 本轮实际完成

历史候选 44 条。通过公开前快照、主要终点版本、来源哈希及独立agent复核的记录 20 条；训练 12 条，测试 8 条。人工双审 0 条，不能称为人工金标准。

训练成功/失败 {'success': 11, 'failure': 1}；测试 {'success': 3, 'failure': 5}。这是一批定向收集病例，不是全行业随机样本。

## 评测方法

方案在首轮模型拟合前保存。训练结果时间早于2023年，测试2023–2025年；测试资产从训练集剔除。缺失值处理、缩放、one-hot只在训练集拟合。模型和超参数固定，没有用测试表现挑参。小样本不拟合校准器。

主要终点条目数是注册库primary measure行数，不等于独立假设检验数，不能据此自动给alpha。领域及终点家族分类为冻结的正则提取，不是临床人工裁定。原始字段和每字段定位可以追溯。

原正式训练200/校准50/测试50及人工双审门槛保持不变。本轮独立的12/6探索门槛仅用于工程试训，不是模型可用性的统计论证。

## 排除原则与具体问题

- 中期futility停试不自动当作最终主要检验失败；LOTUS、AMEERA5、TrilynX、KEYNOTE641隔离。
- TULIP2和NEPTUNE已知主要目标发生更改，旧快照无法证明精确匹配。
- GRADUATE旧快照104周与116周读出不一致；没有更晚且公布前的匹配快照，不能配成同一目标。
- KEYNOTE859主要终点层级的变化被单独隔离；不能用当前实际人数替代2020年的计划780人。
- 混合、部分成熟、源未核实或缺少历史主要终点文本均不补成二分类训练样本。

## 复现与发布

本地使用Python3.11和scikit-learn1.8.0离线训练；服务器只读取冻结结果，不反序列化模型、不在公共请求中触发API。数据、提示词、协议和模型分别有版本和哈希。

已归档原始选行与完整表SHA/ZIP CRC。公开月度归档可重获；为节省本地磁盘，不把全库解压表及临时字节缓存放进发布包。完整表哈希不是可信第三方时间戳，也不是来源签名。

```bash
python predome_data/historical_v2/history_probe/build_snapshot_features.py
python assemble_historical_dataset.py --review predome_data/historical_v2/review_v3.json --output NEW_DATASET.json
python predome_pilot.py --data NEW_DATASET.json --output NEW_RUN_DIRECTORY
# DeepSeek密钥仅由进程环境提供；输出目录必须是新版本，禁止覆盖旧记录。
python predome_pilot_llm.py --data NEW_DATASET.json --run NEW_RUN_DIRECTORY
```

详细优化路线见《Predome_项目优化路线_20261017.md》。下一步优先建设结果无关的采样框、独立失败资产和同适应症前序效应数据，再开展新的、从未用于模型选择的时间留出及真实前瞻评测。

## LLM事实审查与事后诊断

独立审查记录 12 项推理问题，原始API响应和概率未修改。包括无来源的历史成功率、将未知对照断言为非安慰剂、未经SAP确认的多重性规则，以及把时间事件结局一概理解为死亡生存难度。实际调用成功不等于证据合规。

两型号的AUROC均低于0.5，不能把较低的Brier解释为成功的疗效排序。为解释这一点，在看到输出后透明补充固定50%概率的诊断参考：Brier=0.2500、log loss=0.6931；两种DeepSeek均未优于它。这个参考不是方案预设基准，不作为独立优选证据。

训练集11/12成功、测试集3/8成功，使高先验基准在本批明显偏乐观。LLM接近中性的输出可能仅因更接近测试比例而降低Brier；不能据此归因于机制推理或泛化。

train终点家族存在 0/12 个缺失或字面unknown。100%缺失的modality/comparator_type、恒定的phase/randomized均没有新增区分信息；有字段不代表已经有药物机制数据。

test终点家族存在 4/8 个缺失或字面unknown。100%缺失的modality/comparator_type、恒定的phase/randomized均没有新增区分信息；有字段不代表已经有药物机制数据。
