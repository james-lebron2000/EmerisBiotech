# Predome Agent System：70%目标与优化实验方案

版本日期：2026-10-19。用途：研发决策和可审计研究预测。70%是待验证的目标，尚未达到或证明；本文件不代表临床治疗方案有效性、投资收益或获批概率承诺。

## 1. 优先解决的决策

针对一个已冻结的“药物 × 适应症 × 人群 × 对照 × 主要终点 × 分析时点 × 预设成功规则”，预测其首次决定性主要疗效分析是否达到预设标准。PFS、OS及不同生物标志物人群分别登记；多剂量、多主要终点、非劣效和序贯检验不能在看到结果后改写为最有利定义。

现阶段优先把公开的随机试验证据转换为可靠、可检验的输入。增加Agent数量或把几个LLM答案投票，不能代替这一工作。

## 2. 如何判断达到70%

同一批锁定测试研究同时报告以下指标：

| 评价 | 判定与解释 |
|---|---|
| 准确率 | 在训练阶段冻结的阈值上计算，目标≥70% |
| 平衡准确率 | 灵敏度、特异度的均值，目标≥70%；防止只猜多数类别 |
| 多数类别参照 | 同时报告训练集决定的多数类预测，以及测试集实际多数类比例；后者只是事后参考，不能作为拟合预测器 |
| 概率质量 | Brier、log loss、校准图；概率质量改善须优于固定50%及训练数据统计基线 |
| 覆盖率 | 有标签子集内的回答覆盖率与全977项的标签查明比例分开报告。高置信子集准确率不能替代全体准确率 |
| 不确定性 | 按研究药物资产组件重抽样2000次；同一药物的多项研究不视为完全独立 |

研究性点估计目标要求准确率和平衡准确率均≥70%，超过观察到的多数类参照，并使Brier<0.25。较强的“稳定超过70%”证据还要求准确率与平衡准确率的资产聚类95%区间下界均≥70%，且至少50项测试和20个资产；这仍不是临床验证或通用样本量保证。正式200/50/50、独立人工双审等原有门槛保持。

例如独立样本中命中70/100的Wilson 95%区间约为60.4%–78.1%。70%的点估计本身不足以声称真实能力稳定超过70%；资产相关性会进一步降低有效信息量。

## 3. 本轮数据基础与边界

已按固定15家MNC、随机III期、当时计划2021–2025年主要完成的规则，从2020及固定年度AACT快照构建977项研究的中性并集，其中原2020队列338项、新增639项。每项只用最早符合条件的历史基线。原始来源、筛选流程、CRC/SHA和年度去重已经核验。

2022-01-01官方归档URL返回404，未擅自替换，也未计为零项。这个年度存量并集不是所有2021–2025年MNC读出的普查；同年登记且读出、计划改期及别名覆盖等仍可能遗漏。

977项当前注册库资料已实际抓取，其中596项有主要结局统计分析条目，但自动最终标签为0项。统计条目、COMPLETED、TERMINATED、获批、单个名义P值、CTO/HINT弱标签均不能直接替代本项目的主要终点标签。原论文可能是设计稿、安全性延长研究或其他研究；必须逐案对齐历史主要终点及成功规则。

历史输入来自各项最早年度基线；当前注册库仅用于身份、结果与检索审计。结果晚于基线，但同一目标早期部分披露已早于基线的研究，不具备此处的事前预测资格。

## 4. 最有希望提升预测的输入

| 输入域 | 需要采集的字段 | 作用 | 缺失时处理 |
|---|---|---|---|
| 前期随机疗效 | 研究ID、公开日期、随机设计、ITT/PP、效应量、CI水平、原始单位、SE推导、实验/对照方向 | 估计效应强弱与精度，区分真实信号和不稳定小研究 | 保留未知；非随机不能冒充RCT |
| 可迁移性 | 人群、疾病阶段、治疗线数、标志物、背景治疗、对照、终点、随访时长、剂量和暴露匹配 | 识别“前期阳性但后期设计不同” | A/B/C分级；B仅作间接特征，C不输入数值 |
| 目标统计设计 | 分析事件数/终点方差、各臂计划n、单/双侧α、NI界值、alpha分配、层级及中期分析规则 | 估算预设检验通过概率 | 缺关键参数就拒绝给出assurance；不能只由总n猜事件数 |
| 对照与临床变化 | 当时标准治疗、主动对照强度、后续治疗、交叉及时间漂移 | 解释单臂或旧对照信号为何不能复制 | 只用当时可得证据 |
| 药理与安全性 | 靶点验证、组织暴露/靶点结合、剂量反应、停药和关键毒性 | 判断机制链是否存在缺口 | 证据锚定，不能把LLM机制解释当实测结果 |
| 数据质量 | 主要终点版本、来源日期、抽取/复核记录、缺失原因、原文SHA | 防止泄漏和误标签 | 未核实不进入正式拟合 |

HR/OR等比值在log尺度由CI推导SE；风险差、均值差使用自身尺度，单位分别记录。HR有效不意味着OS必达标，肿瘤缩小不等于生存获益，蛋白尿变化也不能自动当作肾功能终点效应。

## 5. 三条技术路径

**路径A：可解释统计预测。** 对直接可迁移的随机证据，用前期效应的不确定性、目标试验精度和实际成功边界积分，计算预测性assurance。若效应与目标估计量的近似分布是独立正态，则通过概率可由效应均值与前期/目标方差组合计算；真实多主要终点、α分配、NI或中期规则必须按相应设计实现。赢家诅咒、异质性及人群/对照迁移折扣需要用训练数据估计，不能手调至命中历史结果。没有目标事件数、方差或明确成功边界时，保留拒答。

**路径B：结构化监督学习。** 本轮保留四个预设基模型：设计Logistic、设计Extra Trees、加入前期随机证据的Logistic和Extra Trees。预处理只在训练折拟合。按药物资产留一交叉预测，以训练集OOF概率拟合非负、和为1的Brier最优组合；分类阈值只在同一训练OOF上按平衡准确率固定网格选择。该组合层的训练分数有乐观性，不称独立交叉验证性能。2023独立校准集仅用于固定Platt；不能选择模型、权重或阈值。2024–2025标签在模型、概率和阈值冻结后只揭盅评估一次。

**路径C：检索与LLM证据审查。** DeepSeek Flash、Pro在相同证据包上独立给出概率、事实引用、假设和拒答。独立审查核对每条事实是否被引用支持；一次预先限定的事实修复保留原输出和修复输出，不按概率方向择优。现已真实完成7项未来试验、10个主要假设的两模型调用及独立事实审查。结果是未校准的研究判断，不能直接称训练模型疗效概率。

未来扩充其他供应商或机制模型时，新方法应使用新的训练/验证周期。看到本轮测试结果后修改的算法，不能继续在同一测试集上宣称首次独立达标。

## 6. Agent分工与可控自进化

1. Intake Agent按固定窗口建立研究队列和版本化原始来源，不读取结果挑研究。
2. Evidence Agent抽取前期RCT效应与目标设计；所有数值附原文、日期、单位和证据等级。
3. Label Steward独立裁定主要终点与首次决定性日期，保留冲突和未知；新测试方向在建模前封存。
4. Predictors在相同输入上独立运行统计、监督模型及LLM，记录拒答和实际调用模型。
5. Review Agent审事实、终点变更、资产重叠、时钟和引用支持；Agent审查不冒充人工双审。
6. Evaluation Agent按冻结方案报告所有方法，不挑最好看的分数；输出版本、模型、输入和预测哈希。
7. Release Agent仅发布冻结产物。新真实结果进入隔离标签库；触发下一版本评估，通过既定门槛后再替换线上版本，保留回滚与旧预测。

“自进化”具体体现为累积新证据、纠正可追踪的数据错误、增加已核实标签并进行下一轮受控训练。线上模型不能自行改旧预测，也不能看见未来结果后覆盖预测概率。

## 7. 先做哪些增益实验

按信息来源逐步消融：设计 → 加前期效应/SE → 加人群/对照/终点/时间匹配 → 加剂量暴露与试验统计边界 → 加机制证据。在独立资产的训练验证上检查增益，报告正负两类混淆矩阵、Brier和缺失覆盖。某一信息域无增益就保留为审查证据，不强行输入模型。

优先补齐对预测最关键且能核验的字段。不要先训练庞大生物基础模型，也不要用虚构的“虚拟患者数”代替真实疗效标签。胃癌、肠癌可作为后续有组织/治疗/随访数据的专病验证线，但不能只保留恰好表现好的癌种再回称全MNC预测能力。

## 8. 工程实现与目前未完成的验证

新增实现为 `continuous_dataset.py`、`continuous_audit.py`、`continuous_model.py`、`continuous_ensemble.py`。拟合入口复查完整队列、每项最早基线、来源哈希、主要终点数、计划/实际入组区分和前期RCT时钟；不满足门槛就不训练。历史标签策展、独立校准、回测与前瞻命中率仍必须分别完成，不能由通过软件测试推导。

相关冻结协议包括 `protocol.json`、年度并集修订、`performance_goal_contract.json` 与阈值来源修订。后者明确唯一主候选是训练OOF组合，禁止看到测试结果后挑某个基模型作为70%成功案例。

## 9. 方法参考与不可外推的指标

- [HINT原始研究](https://arxiv.org/abs/2102.04252)：利用分子、疾病、入排标准及药代知识整合预测；论文摘要报告III期PR-AUC为0.623。PR-AUC不是准确率，其目标、标签及样本来源与本项目也不同，不能移植成Predome能力。
- [SPOT原始研究](https://arxiv.org/abs/2304.05352)：按主题及时间组织试验，展示时间结构的价值；其PR-AUC提升不等于本项目准确率提升多少。
- [TRIPOD+AI](https://www.bmj.com/content/385/bmj-2023-078378)：要求透明报告建模、调参、数据差异、阈值来源、区分度及校准等。本项目借用报告与验证原则；研究单位为试验/资产，不能把患者级临床预测标准直接视为已经满足。

本方案将“能否超过70%”变成可推翻、可复现的实验。当前没有证据支持对全适应症、全部未来MNC研究承诺70%以上准确率。
