# 公开读出日历

公开页的赛程入口直接使用既有公开投影中的时间窗口、模型记录和来源。它不调用模型、不改写冻结目标或原预测，也不以试验完成日期代替公告日期。

## 展示规则

- 依据 `readout.start/end/precision` 校验年度、半年、季度、月份或单日窗口。缺失、非法、倒置或粒度不匹配的范围显示 `Readout unconfirmed`，保留原始标签，不从文字猜测日期。
- 同年窗口按结束边界、试验名及记录 ID 稳定排列。重叠窗口不是确切公告顺序；页面称 `Recorded guidance`，不声称这些历史指引已经重新核验为最新日程。
- 药物项目级指引单列 `Program guidance`，不冒充某项试验专属承诺。没有公告时间的独立 pilot 单列，不纳入正式赛季。
- 每张卡只统计同一目标的 `clinical_only`、`same_evidence` 已分配记录；历史回放仅使用其原有 archived 记录。失败、拒答与未执行继续计入 Uncertain 和全部已分配分母，不混入专利条件或其他 Agent 赛道。
- 同时存在 Success 和 Failure 才显示方向分歧；全体 Uncertain 显示 `No directional call`。日历不产生成功概率、准确率、名次或赢家。
- 锁定时间来自存储字段，缺失显示未知，部分缺失明确标注。它不是独立时间戳机构提供的时间证明。
- 原来源链接独立于试验选择按钮。Reported 按 `result.first_public_at` 逆序，历史回放继续标注不属于事前命中；原有结果接纳及计分条件保持不变。

## 本轮记录范围与检查

本地实际公开 API 捕获包含 12 项正式试验和 1 项独立 pilot 的待公布赛程：2026 年具名试验 5 项、2027 年具名试验 6 项、VITALIZE 项目指引 1 项，以及公告时间未确认的 TRIUMPH-5。正式目标的时间字段逐项对照冻结 spec 保持一致；这不是对当前申办方最新日程的重新查证。

浏览器 fixture 加载实际生产 HTML、CSS 和 JavaScript，覆盖严格日期、闰年、窗口归类、来源点击、全部分配记录、缺失锁定时间及 Reported 顺序。字号检查要求新增日历的来源、锁定时间和指引至少 10px，试验名和窗口至少 12px。1440×900 允许少量滚动，避免把可读性让位给硬性零滚动；375px 保留响应式布局。

[真实记录截图与来源说明](images/readout-calendar-20261027/provenance.json)来自临时运行库副本上的本机 HTTP GET，使用实际公开记录和交付的静态文件，明确标注本地候选、未部署。它们没有新增预测、访问模型或写入生产状态。合成 UI fixture 与实际记录截图的验证范围分开保留。

部署清单同步纳入修改后的 `static/arena-public.html`，与 JavaScript、CSS 一起核对提交字节，避免部署后仍加载旧资源引用。离线代码包、工程检查和截图均不代表服务器更新或临床预测效度。
