# Predome 1.2.1 public and internal presentation

The public home and `/arena` show one exact clinical target in three modules: trial facts; actual model directions with model version and record time; consensus and the reported clinical outcome. `Upcoming` and `Reported` remain separate. Historical replay is labelled and cannot earn a prospective match. Current raw LLM values have no established clinical calibration, so public probability and confidence are N/A. No model values or historical outputs are rewritten.

The public browser uses only `/api/arena/public`, target detail and its clinical-record export. These are field-allowlisted read-only projections. Registry phase, design and status require a matching frozen registry file, SHA, size and NCT. Missing fields remain missing. Model prose that reports its own numerical forecast is removed from the public rationale; clinical HR, CI and p-value facts remain source-bounded.

The internal interface is `https://8.148.145.28:18443/arena/lab`, using existing sessions and `EMERIS_ARENA_LAB_USERS`. The configured user is `jake`, corresponding to the existing Jake login (account names are normalized to lowercase). This grant does not confer clinical result adjudication rights. Sign in at the standard HTTPS `/data` page, then return to the internal port. No new password is created or changed. The internal UI is read-only; paid execution remains an operator CLI action.

`configure_arena_frontends.py` replaces only the existing Emeris Nginx site after pinning its SHA and confirming app1.2.1. It retains a backup, tests Nginx, hot-reloads, and restores old bytes if the change fails. Public443 denies raw Arena/debug endpoints and old debug HTML; only the public projection and manifest-bound published source attachments remain available from the Arena namespace. Internal18443 protects raw API requests with an authentication subrequest. The original dashboard calendar remains at `/arena/lab/calendar`; legacy read-only pages and APIs can be reached from the authenticated internal port. Public `/track-record` redirects to the sanitized Reported view; the model-analysis page is available through the authenticated internal port.

Legacy anonymous forecast, evaluation and snapshot exports are also restricted at the public reverse proxy, including the old product, dashboard and Predome research APIs. Their read-only pages redirect to the internal port. The existing authenticated `/data`, `/predict` and `/research` workflows retain their own public-port login, CSRF and ownership checks; their upload, mapping and private report APIs are not blocked. The internal port is a read-only view: legacy scenario submissions there are not enabled.

No unrelated Nginx site, original clinical file, existing user password, or frozen model output is modified by this presentation split. Session login tests use an isolated QA runtime. Deployment and real external-port verification are independent checks; consult the final release and frontend receipts rather than inferring production status from this document.
