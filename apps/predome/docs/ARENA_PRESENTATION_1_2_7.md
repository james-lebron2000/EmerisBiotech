# Predome Arena 1.2.7

The public view adds readout-stage schedule cards, a categorical model face-off and an official-result reveal panel to the existing three clinical modules. All counts and names derive from the exact target's stored clinical-only model records. Failures and abstentions stay Uncertain. Unanimous Uncertain entries are not described as directional agreement. There are no ranks, wins or calibrated probabilities. Historical replays remain excluded from prospective standings. The prediction algorithm and ledger are unchanged.

The fixed code-only deployment retains database backups, frozen-event prefixes, sealed clinical rows, external configuration and original workload checks. Browser checks compare every face-off count to the actual stored rows and preserve safe public GET requests only.
