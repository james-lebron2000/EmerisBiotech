公开真实队列、合成药筛和冻结预测各有适用范围。页面明确标记数据类型与证据日期。

新功能：研究工作单 ↗

临床预测产品：从输入到核验

先在 读出日历选择真实试验，查看目标、概率、证据与公布窗口；在 Predict a Trial 输入 NCT、上传 PDF/DOCX 或编辑结构化字段。证据审查和条件统计场景可直接运行，外部模型不可用时明确显示状态。

报告默认私有。正式预测经用户选择后锁定为不可覆盖版本；结果公布后由独立审核者核对具体终点、人群、治疗比较和来源。预测与实际结果将前瞻记录和历史回放分开展示，模型分析显示样本量、校准和基线。研究概率未经临床效用验证。

从这三个入口开始

01 / DATA

整理研究队列

选择胃癌或结直肠癌公共快照，或导入有权使用的去标识化 CSV / TSV。确认字段、单位和质量后，查看人群构成与版本记录。

输出：可追溯的研究表、字段映射与报告。个人数据工作需要登录。

进入数据工作台 ↗
02 / EXPERIMENT

运行分析与实验演练

免登录运行公共队列描述性分析，或改变模拟供体数、随机种子与噪声，查看仿真 PDO 药筛曲线和评估结果。

输出：结果 JSON、数据 CSV、HTML 报告。仿真化合物不对应真实药物。

进入研发实验台 ↗
03 / TRIAL LAB

比较候选与整理证据

查看正式预测和证据目录，选择最多3个候选，记录研究问题与下一步，再导出讨论报告或可重新导入的工作单。

输出：冻结记录、设计情景与研究工作单。候选不具备模型条件时不输出概率。

进入试验研究台 ↗

完成第一份研究工作单

  1. 在试验证据中搜索药物、药企或 NCT 编号，核对证据截止日期和官方来源。
  2. 点击“加入研究工作单”，并排查看主要终点、读出窗口、已发布预测和待补证据。
  3. 填写研究问题、下一步与所需证据。工作进度用于项目整理，不代表临床成功或失败。
  4. 点击“保存到本机”保留当前浏览器内的内容，或导出 JSON 跨设备继续编辑；HTML 适合讨论阅读。
  5. 导入 JSON 时先检查预览，再点击应用。导入的备注不会改写正式预测。

本机工作单不随账号同步，同一浏览器使用者可见。需要清理时使用“清除本机工作单”。产品不会主动把工作单发送给他人。

怎样读懂正式预测

预测 HR＜1 的概率表示数值方向有利；主要终点达到统计学优势还取决于事件数、检验规则和不确定性。敏感性表展示固定假设变化下的结果，不能作为事后挑选预测的工具。

目前正式记录覆盖 PACIFIC-9 的两个共享对照比较，概率未经临床校准。网页情景参数不会改变冻结数字；结果裁定需要匹配官方来源、治疗组、人群、终点与分析时点。未披露保持待定。
