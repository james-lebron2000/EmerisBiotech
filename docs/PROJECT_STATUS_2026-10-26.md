## Arena 已交付范围

1.2.7 展示药物管线赛程、指定试验的模型方向对比及官方结果揭示，保留模型版本、生成时间、短依据和来源。失败与拒答保留为不确定，未校准概率显示 N/A；未公布结果的目标不排名。历史回放和前瞻预测分别展示，历史结果不计为事前命中。

本次只读接口核对显示，当前正式赛季 `of-season-20261023-corrected-v1` 有 **12 项目标、0 项正式裁定**。计数只选择 `cohort_id` 等于 `current_cohort_id` 的目标，排除旧赛季、试点、消融记录和历史回放，避免把同一试验的多个研究版本重复计为正式目标。

健康接口同时报告 `clinical_use=false`、`formal_training_completed=false`、`clinical_prediction_validated=false`。零正式裁定无法支持准确率或命中率结论，也不能证明其他来源没有新公告。

## 研发与后续工作

27B 后训练与 Agent 仍处于方案阶段。基座 revision、GPU 和预算、可合法使用且通过审核的训练清单、真实审核人员、训练兼容性及独立校准均需落实。计划样本数、拟议实验和工程检查不能写成已经取得的训练结果。

后续按以下依赖推进：

1. 审阅并集成 PR #3，核对合并后源码与发布映射；合并本身不自动发布服务器。
2. 对正式目标逐一核对人群、比较、主要终点和统计成功定义，形成可追溯、经独立审核的结果标签。
3. 核实专利接口授权、资料用途权利与科学审核状态；取得资料不等于拥有训练或商业再分发权利。
4. 在独立研发项目落实数据及资源后建立简单基线，再开展后训练、Agent 和证据增益比较。
5. 冻结系统后进行前瞻评估；商业价值、团队使用效果和投资收益另行验证。

活动执行稿、FAQ 和演示材料属于准备工作，现有文件不能证明活动已举行、邀请已发出或客户已转化。
