# 临床资产研究工作台 UI 迭代验收 — 2026-10-17

本轮由三个并行 subagent 分别负责共享界面外壳、临床登记检索、官方披露核对；主 agent 完成首页、导出页、整合及运行服务验收。范围是当前本机工作台的 UI 与使用流程，未进行远端上线或新容器镜像发布。

## 已实现

- 共享深蓝／青绿界面、分组侧栏、活动页面高亮、面包屑及跳至主要内容入口。资产页直接进入导航。
- 窄屏导航使用默认折叠的原生 details，不再占据大半个首屏；无脚本、外部字体或外部图片依赖。
- 首页显示数据库实际指标、采集队列、研究入口和最近历史；演示资料单独收纳，不用于真实指标。
- 市场页提供具备标签的筛选字段、结果范围、完整保留条件的分页和导出，四列表格分层展示公司／NCT／标题、干预、阶段及来源。
- 官方披露使用自适应来源卡片、紧凑日期、名称关联指标与可聚焦五列表格。缺失字段、失败、旧成功快照与来源边界仍明确展示。
- 导出页展示固定筛选、中文阶段／状态、行数、文件大小、下载按钮、生成时间及完整性依据；可返回原筛选。
- 含时区的抓取／导出时间显示 UTC+8／台北，原始 ISO 保留；日期／月度来源维持其原有精度，无时区值不推测时区。
