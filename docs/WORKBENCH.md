# 研究工作台

打开 http://127.0.0.1:18764/ 。服务停止后，在 Finder 双击本目录 `启动研究工作台.command`，保留终端窗口；Ctrl-C 停止服务。无需 API 密钥。

- 概览：历史运行/快照/循环数量与最近记录。
- 历史记录：搜索、类型筛选、详情、报告、证据、结果与日志。
- 任务观测：从快照详情发起完整性校验，运行中自动刷新；显示成功、失败及重启中断。不会自动做科学审批。
- 问题与笔记：录入作者和内容后保存，可在单条记录详情关联笔记。记录只追加，不覆盖原分析。

当前是本机备份视图。分析运行来自 2026-09-25 16:56 的备份，研究快照与循环来自 2026-09-25 23:57 的备份；不保证包含外置盘此后的新记录。页面顶端持续显示这一边界。因外置盘访问长时间阻塞，原始输入校验在备份视图中禁用，本地研究快照可以校验。

活动数据在本机应用数据目录内的 workbench.sqlite3。笔记和校验任务同时导出到本目录 artifacts/workbench/history.json；源码与历史快照存于本目录。备份时应在停止服务后复制 SQLite 和本目录；恢复时保持 notes/jobs 表，不将其当作科学审查记录。外置盘的历史记录从未被此界面改写。

源码可在原项目中通过 ./vbt workbench 启动源数据视图；外置盘稳定前建议使用此本机入口。当前没有自动同步机制，不能把本机备份视图当成实时下载进度。
