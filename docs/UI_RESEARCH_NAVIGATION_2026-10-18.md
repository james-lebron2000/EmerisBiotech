# 临床资产研究的检索、证据和历史入口

本轮在已有深蓝与青绿工作台基础上，由 UI subagent 实现页面交互，独立 subagent 核查路由、导出、安全和历史范围，主任务整合样式、运行版本与浏览器验收。范围是本地单用户工作台的可用性。

## 研究路径

- `/assets` 公司入口支持上市市场与公司名称、证券代码、已存申办方联合检索。进入公司及返回入口保留目录上下文；分页保留市场和搜索词。重复的查询边界与失败原因默认折叠，关键状态仍直接可见。
- `/market` 保留原表格，并提供折叠卡片视图。每项试验可进入同公司、同 NCT 的登记用药关联和登记变更。卡片保留干预名称、适应症、来源日期、观测日期及原文校验记录。
- 检索条件显示可单项移除的标签。清除其他条件时保留公司上下文；切换显示方式和分页保留筛选。
- 变更先按市场、公司和明确 NCT 过滤再取最近十条。普通关键词、阶段和登记状态不用于推算历史状态，页面明确说明这个范围。展开可查看完整 before/after 和采集运行编号。
- CSV 导出继续保存全部匹配结果的快照；显示方式和当前页不改变导出范围。原 POST、Host、Origin 和 token 校验保持有效。

## 解释边界

已存登记观测、临床成功、药物权益和完整管线覆盖分别核实。名称卡片的阶段和角色汇总仍按原有规则处理：条件命中名称后，保留该名称全部试验依据，不推断药物最高阶段。没有已存变更不能推断没有研发变化。校验值展示不等于本页重新检验原件。

本轮不下载研究数据，不更改主体关联、不提交科学判断，不修改研究运行和原始证据。

## 发布与验收

只发布 `ui_shell.py`、`market_view.py` 和 `market_asset_view.py` 三个 UI 模块。并行开发的英文法人名、申办方关联和离线披露接入代码独立保留。

隔离发布候选由上一版提交 `1dd3455` 加本轮三个 UI 模块与两个测试文件构成，最终 **439 项相关回归全部通过，0 失败、0 跳过**。独立 subagent 的重叠聚焦范围另有 **175 项通过**，两个数字不相加。测试涵盖筛选、50/200 分页、失效页码、公司与 NCT 隔离、缺字段、恶意文本/来源链接、导出范围及原有 HTTP/CSRF 约束。

UI 代码发布提交为 `a8d28c8`（包含 `29a7404` 的页面交互和随后的小屏字号调整）。受管服务发布前保存三个旧模块、launchd 配置和四个一致 SQLite 备份，确认没有正在执行的采集任务，并通过 `quick_check=ok`。发布后 **53 个运行模块与该提交逐文件一致**；服务配置、PID、端口归属及应用响应共同核验通过。三个市场公司入口、登记表格/卡片、历史列表和首页共七项 HTTP 检查均返回 200。

本机截图、精确版本、前后文件 SHA 和服务状态保存在忽略目录 `artifacts/market/ui_iteration/2026-10-18/`。主要文件为 `acceptance.json`、`visual-acceptance.json`、`deployment.json` 和 `deployment-final.json`。截图和生产状态数据库不进入公共 Git。

## 实际页面核对

| 实际操作 | 观察结果 |
|---|---|
| 公司入口选择 A 股并搜索恒瑞 | 显示一家公司；进入公司后，市场和公司搜索上下文保留 |
| 在公司页搜索 `NCT06057610` | 匹配三个登记名称；这些名称关联三个去重 NCT，名称卡片继续保留全部依据 |
| 展开该试验依据并进入登记变更 | 明确显示恒瑞、该 NCT 及两条已存变更，展开后显示观测时间和采集运行编号 |
| 切换为卡片并撤销 NCT 关键词 | 保留公司与卡片视图，显示该公司 570 条已存关联，每页 50 条 |
| 再筛选 PHASE3 | 返回 133 条公司—试验关联，当前显示 50 张卡片；不是 133 个独立或自有资产 |
| 1440px 桌面 | 双列各 533px；页面宽度 1440px，无页面级横向溢出 |
| 390px 手机，展开原文与 SHA | 单列 324px，原文说明 12px；页面宽度 390px，长地址与校验值正确换行 |
| 清除临时视口覆盖后 | 默认 359px 视口与页面宽度一致，工作台页面保留供用户使用 |

上述是工程和抽查页面验收。本轮没有完成公网发布、客户账户权限或临床预测有效性验收。
