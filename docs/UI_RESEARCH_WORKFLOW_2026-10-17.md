# 临床资产与研究历史 UI 验收 — 2026-10-17

本轮由 UI 子任务完成资产页和申办方核对页，独立子任务审查导航、研究范围和信息层级；主任务整合研究历史、首页范围说明、响应式样式，并统一完成浏览器验收。沿用已有深蓝／青绿侧栏，不增加模型、脚本或外部字体依赖。

## 使用流程

- `/assets`：按证券主体、药物／试验／适应症关键词及用药角色组合筛选。显示登记名称数量、按 NCT 去重的试验数量和待核对权益。原文名称不直接等同独立资产；登记阶段不推断最高研发阶段。
- 名称卡片在宽屏分两列，窄屏单列。长适应症列表显示预览，可展开完整原文。每项试验展开后保留角色、阶段、适应症、来源更新时间、本地观测时间和历史可见性；另可查看批次、SHA-256、来源链接及最近查询尝试。
- `/records`：关键词、类型、执行／记录状态、科学审查分别筛选；保留筛选值与当前条件。表格能通过键盘局部横向滚动，记录链接保持版本编号。
- 旧记录中的明确 `SYNTHETIC ENGINEERING TEST:` 标记增加中文徽标。计数仍包含原存档，首页与历史页说明其中有多少合成工程测试；未标记的记录也不因此获得真实临床验证状态。
- 科学审查旧值 `pass` 与 `passed` 在同一个“通过”筛选项下检索，原始记录不修改；执行成功不能替代科学审查。
- `/mapping`：待核对建议默认展示主体、申办方、匹配方式、来源和状态。核对表单、近期检索与核对历史默认折叠；展开后明确说明接受后登记关联并排队抓取。保留原 POST、token、字段与输入约束。自动来源核对明确不是人工签署。
- 首页将当前本机市场采集与历史研究备份分开标明范围，备份说明原文可展开。记录问题的按钮与其实际功能一致，不暗示自动启动分析。
