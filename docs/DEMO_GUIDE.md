# EmerisBiotech 产品演示

本版本支持本地单用户的研究浏览和判断留痕。内置内容不依赖原始研究数据或模型密钥：一个 OSMR/UC 回顾案例、两个未验证研究草案。已知结局案例只能展示工作流程，不能证明预测能力。

## 启动

安装 Python 3.11 和 uv 后，在仓库根目录执行：

```sh
uv sync --extra dev --frozen
uv run vbt --workspace "$PWD" workbench --port 18764
```

打开 http://127.0.0.1:18764/ 。终端需要保持运行；Ctrl+C 停止。若端口被占用，先检查已有服务，或改为 `--port 18765`。服务只监听回环地址。此命令不下载研究数据；首次安装需要获取软件依赖。

## 六分钟现场流程

1. 首页：说明研究平台目标和当前阶段，进入“体验一轮研究”。
2. OSMR 案例：先读问题，再对照观察性关联与临床反证，展开来源边界。说明这是截至 2026-09-25 的回顾资料。
3. 记录判断：填写演示昵称，选择继续补证据、修订或停止，写至少十个字符的依据。保存后的时间线会保留历次判断。
4. 刷新页面：确认记录仍在。演示判断与正式运行、科学审批分开存放。
5. 历史：已有工作区可以打开成功、失败及受阻记录，阅读摘要、附件和完整技术记录；新安装会显示真实空状态。
6. 目标与里程碑：说明前瞻预测、独立验证和成本后投资表现的后续验收条件。

## 展示边界与数据

- 两个草案是研究问题，不是公司自有药物资产，也没有已落实的实验结果。
- 内置回顾案例是固定摘要，没有实时调用模型、重跑分析或刷新临床信息。
- 保存的演示判断不会修改案例原结论，也不自动启动分析。记录人为自述身份，不等于独立审查签名。
- SQLite 在本机应用数据目录；可读导出位于工作区 `artifacts/workbench/history.json`，演示记录字段是 `demo_decisions`。日常恢复应保留原 SQLite；JSON 导出不提供自动回灌工具。
- 同一 workspace 路径对应同一状态目录。不要并行启动同一工作区服务；本版本没有多用户权限隔离。
- 本地缓存若存在，会显示备份日期；不能将它说成实时同步外置盘。
- 尚未完成公网云部署、经校准的临床预测或投资收益验证。

## 验收

```sh
uv run pytest -q
```

自动测试覆盖演示保存、重启读取、非法输入、HTML 转义、案例隔离及 HTTP 操作；浏览器人工验收需要另行记录，不能由测试数量替代。
