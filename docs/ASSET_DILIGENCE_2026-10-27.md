# UC 资产资料、范围与缺失矩阵

关联 [Issue #31](https://github.com/james-lebron2000/EmerisBiotech/issues/31) 与 [PR #7](https://github.com/james-lebron2000/EmerisBiotech/pull/7)。这是可审阅的资料整理流程，不是资产权利调查完成、法律意见或可交易性认证。

## 数据与判断

同一参考资产可追加多个地区、用途、权利类型及时间范围的主张；资料对项目假说的支持、反证与未知分别记录，来源内容另行审阅。九个资料领域为申办、开发主体、专利申请、专利授权、许可、所有权、科学差异化、开发风险与交易假设。不同来源并存，不按录入顺序自动裁决；相同领域也不能推定覆盖了全部地区或用途。

资料必须精确关联本项目的资产事件及分子名称。支持／反对主张必须引用该资产绑定登记或本项目已有研究证据；未知可以没有来源。网页来源仅绑定已有记录，不访问网站或声称核实其当前内容；本地来源在读取时按绑定 SHA-256 核对，摘要上限 1 MB。单资产登记下载使用精确 asset_id，不再从最后一条资产导入选择文件。资料日期来自绑定来源；覆盖起止日期单独填写，unknown 不表示当前有效或全球覆盖。

每项资料保留限制、缺失材料与下一项核查。实际审阅人可追加判断、理由、所审范围、反证和下一步；署名为本地声明，未认证身份、专业资格或法律有效性。审阅支持也不会自动清除所录缺失材料，不改变参考资产的 not_established 权利状态。

## 版本、冲突与独立决策

所有新增记录沿用程序的追加事件、哈希链和 revision 并发检查。项目定义、证据／结果或其审阅、来源导入改变，旧资料提示需要重审；来源丢失或哈希变化时保留历史并提示异常。新资料加入后旧审阅需重新面对完整资料；追加一次审阅不会使它自身或同一依据下其他审阅失效。

资料依据版本与完整矩阵版本分别保存。矩阵包含审阅版本，资料或审阅变更后旧 BD 判断显示需核对。保存新的 BD 记录须引用所选资产全部资料，包含反证、未知及过期记录，并确认资料缺口。过期记录允许在明确披露后用于暂缓、收集资料或不推进的记录，同时保存 stale_claim_ids；不会因历史记录不可修改而永久无法记录暂缓理由。没有权利认证或买卖推进动作。研发决定、证据科学审阅与 BD 状态互不自动改变。

科学风险审阅也绑定新增资料与资料审阅事件。AI 上下文升级至 schema 4，模型提示版本为 uc-research-json-2，带有资料范围、缺口、来源版本、审阅解释与可引用标记，去掉记录人、文件系统路径和完整历史。旧草案与任务上下文会提示过期；只有当前且有来源的 assetclaim 引用可用于新草案。自由文本仍需在模型发送前检查，导出不会自动外发。

## 既有 UC 整理入口

```sh
uv run python scripts/import_uc_asset_matrix.py \
  --state-dir "$VBT_UC_STATE" --program osmr-uc-independent
```

前提是已有 UC 项目和唯一匹配 Vixarelimab / NCT06137183 的绑定记录。脚本只读既有记录及登记字节，不下载资料。写入两条登记级资料解释（申办、试验级开发风险）和七项未知，均待审阅；覆盖日期限定为所绑登记更新日。它不从研究关联补造药物差异化，不生成审阅、实验、负责人、预算或决定。

重复运行核对同一准备内容后保持幂等；中断时仅复用完全一致的已追加资料，依据变化或重复匹配则停止并要求核对。已有完整导入的依据发生变化时不会自动覆盖或重复导入。

## 页面与导出

项目的“资产与 BD 尽调”包含资料、全部审阅历史、缺失清单、录入及审阅表单。入口 `/programs?id=<program>#asset-matrix`。

- `/program/asset-matrix?id=<program>&format=md|csv|json`：资料和缺失矩阵。JSON 包含完整资料审阅历史及版本；MD/CSV 供核查和资料任务分发。
- `/program/asset-source?id=<program>&asset_id=<asset-event>`：核对精确资产绑定的本地登记字节。
- `/program/export`：保留所有追加事件的完整项目包。

CSV 文本防公式注入，Markdown／HTML 转义输入；HTTP 写入继承 Origin、CSRF 和 revision 检查。模型不能借资料文字增加执行权限。
