# 中国药物临床试验登记公开来源接入审计

审计日期为 2026 年 10 月 17 日，实际有界请求发生于 16:00–16:05（Asia/Taipei）。本次仅观察公开网站与试验登记元数据，不下载研究数据集，不修改生产数据库，不改变工作台代码或运行服务。

## 验收结论

**CDE 公开登记来源接入目前为 `blocked_access_verification`。没有创建生产采集器或离线试验 parser。** 官方主页可以读取公开搜索表单；按该表单对一个已知恒瑞项目提交的实际查询，以及高级查询入口，返回 HTTP 202 与无可读正文的脚本访问校验响应。没有取得可验证的试验列表、试验详情或分页契约。查询结果数量为**未知**，不能报告为零，也不能把主页可访问视为中国管线已接入。

原始观察、响应头、请求方法与表单、抓取时间、大小及 SHA-256 保存在 Git 忽略目录 `artifacts/market/china_registry_source_audit/2026-10-17/`。此审计报告可以公开，原始归档含源站自动下发的访问 Cookie 响应头，不随公共 Git 提交；这些 Cookie 未被回放或用于后续请求。

## 已核实的官方来源与实际协议

[国家药监局药审中心首页](https://www.cde.org.cn/)在“登记备案平台”和“临床及 BE 备案”处直接链接到[药物临床试验登记与信息公示平台](https://www.chinadrugtrials.org.cn/)。这是本次入口来源，未使用第三方数据镜像。

实际抓取的登记平台主页返回 HTTP 200。HTML 的搜索表单明确给出以下公开请求：

```text
POST https://www.chinadrugtrials.org.cn/clinicaltrials.searchlist.dhtml
Content-Type: application/x-www-form-urlencoded

keywords=SHR-1701
```

表单原始属性为 `action="/clinicaltrials.searchlist.dhtml"`、`method="post"`，输入框名称为 `keywords`。这证明公开页面的正常表单协议，**不证明存在 JSON API、批量访问授权或稳定的自动化服务承诺**。

同一主页还明确链接：

- 试验公示和查询：`/clinicaltrials.prosearch.dhtml`。
- 高级查询：`/clinicaltrials.prosearch.dhtml?pro=y`。
- 查询帮助：`/snipet/437.html`。
- 关于平台：`/snipet/434.html`。

本次没有请求猜测的 `/api`、内部 JSON、分页参数或详情 ID。高级查询参数、结果分页请求、页大小、记录总数、详情 URL 结构与更新/版本字段均未从正常返回中核实。

[国家药监局政务服务门户的药物临床试验登记说明](https://zwfw.nmpa.gov.cn/web/taskview/11100000MB0341032Y100207202900001)可用于核对该登记业务的监管背景与联系渠道；它不能替代具体试验列表，也不能据此推断交易所药企的完整管线分母。

## 恒瑞项目探测与实际访问结果

采用 `SHR-1701` 作为**名称探测词**。恒瑞[2021 年 9 月 15 日的官方项目公告](https://www.hengrui.com/en/media/detail-51.html)实际返回 HTTP 200，正文含该代号，能够证明这是一个有一手来源的探测名称。本审计不据此推断截至今日的药物权益、临床状态、疗效或当前研发阶段。

| 观察对象 | 正常请求 | HTTP | 正文字节数 | 结果与边界 |
|---|---|---:|---:|---|
| CDE 首页 | GET `https://www.cde.org.cn/` | 200 | 85,816 | 官方入口链接可核对 |
| 登记平台主页 | GET `https://www.chinadrugtrials.org.cn/` | 200 | 43,124 | 可核对公开搜索表单，无试验列表 |
| 关于平台 | GET `/snipet/434.html` | 202 | 25,677 | 脚本访问校验响应，无可读正文 |
| SHR-1701 查询 | POST `/clinicaltrials.searchlist.dhtml`，`keywords=SHR-1701` | 202 | 25,265 | 无可读试验结果，数量未知 |
| 试验公示和查询入口 | GET `/clinicaltrials.prosearch.dhtml` | 202 | 25,595 | 未得到高级查询表单或分页契约 |
| 恒瑞探测词一手来源 | GET `/en/media/detail-51.html` | 200 | 9,326 | 仅锚定历史项目名称 |
| ChiCTR 补充来源单条探测 | GET `https://www.chictr.org.cn/showproj.html?proj=194190` | 405 | 2,657 | 未取得正常记录；不能作为 CDE 的替代接入 |

所有请求均使用 HTTPS，系统 TLS 验证结果为 0；不跟随重定向，单次最多 25 秒、响应最多 2 MB，没有重试访问校验。每个响应均保留实际 HTTP 状态。HTTP 202 在这里不是登记查询成功，也不被改写成 HTTP 403；其正文确实没有可读试验内容，并包含带 `r="m"` 标记的混淆脚本。该分类是基于响应内容的接入判断，不是对源站访问政策或验证供应商的推断。

发现访问校验后，没有执行、逆向或解混淆这些脚本；没有请求校验脚本资源、回放 Cookie、登录、处理 CAPTCHA、轮换代理、关闭 TLS 验证或变换隐藏端点继续探测。ChiCTR 的 HTTP 405 原样保留，未改用其他方法反复尝试。补充来源只表明另一个公开注册平台的单条入口也未在本环境取得正常记录；它不能证明该平台没有这些试验。

## 可见字段与仍缺少的契约

通过第一方公开页面的索引文本，可以看到部分登记查询列表曾展示序号、登记号、试验状态、药物名称、适应症、试验通俗题目，以及当前页、总页数和记录总数。例如[一个公开列表页面](https://www.chinadrugtrials.org.cn/clinicaltrials.searchlist.dhtml?keywords=CTR20231537)具有这些栏目。**这是第一方页面的索引观察，不能当作本次直接 HTTP 查询的实时原始记录，也不足以建立解析器。** 本次 SHR-1701 探测没有取得任何可接入的 CTR 行。

| 建立可信接入必须核实的内容 | 本次状态 | 平台处理要求 |
|---|---|---|
| 登记号及稳定详情链接 | 未从本次正常详情响应取得 | 保留 CTR 原始 ID；不得用药名生成伪 ID |
| 完整申请人/申办主体及版本 | 未核实 | 与上市主体及子公司分别记录；不能等同资产权益 |
| 药物名、研发代号、曾用名及标准化关系 | 未核实 | 保留原值，别名关联需额外来源 |
| 方案编号、阶段、设计、试验目的与对照 | 未核实 | 阶段不能只凭标题推断后视为已核实 |
| 主要终点、时间框架及统计/入组单位 | 未核实 | 不足时不得支持成功概率预测标签 |
| 招募/试验状态、计划与实际入组、起止日期 | 未核实 | 各状态与日期分开，不把“已完成”当作终点成功 |

| 分页参数、页大小、总量、排序与快照一致性 | 未核实 | 无法完成总量核对时不能报告全量覆盖率 |

1. 由获授权的研究人员通过源站正常公开查询流程，取得 SHR-1701 至少一页完整搜索结果、一条详情和下一页/总量信息，或源站实际提供的 CSV/HTML 导出。保留原始文件、完整来源 URL、查询条件、导出/观察时间、页面位置与 SHA-256。人工可以按站点正常要求操作；本代理不自动处理访问校验。

3. 收到可验证的原始记录后，先实现纯离线列表/详情解析器：严格识别 HTTP 状态与真实内容，拒绝校验页；核对表头、CTR 唯一性、跨页重复、总量、页码、缺字段与版本。用实际归档建立可复查样本，再另建合成故障测试。仅通过合成测试不能宣称实际来源已经接入。
4. 再决定采集调度、来源允许列表与持久任务接入。未满足上述门槛前，客户覆盖页继续保留“中国登记来源未接入/访问验证阻塞”的缺口；CTGov 关联结果保持自己的来源范围，不扩大为中国全管线覆盖。
