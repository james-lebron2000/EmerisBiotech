# UC 逐项对照与风险审阅

对应 [Issue #28](https://github.com/james-lebron2000/EmerisBiotech/issues/28)，接在 #4 / PR #7 的版本化项目基础上。当前交付对照导入、来源查看、本地审阅声明、失效提示及报告导出。原作者资料缺口、实际独立科学审阅和实验验证仍未完成。

## 输入与导入

只读既有 `uc_independent_20261025` 封存目录。导入 `claim_comparison.csv` 的 18 项原始字段、封存报告与状态，并绑定表中引用的文件。当前实际共核对 18 个文件；逐文件 SHA-256 与原 manifest 一致。单文件最多 1MB，总量最多 8MB／40 个文件；路径必须位于绑定目录。该核对只覆盖这些文件，不宣称重新验收全部原始数据或整个封存包，也不认证 manifest 的独立真实性。

```sh
uv run python scripts/import_uc_comparison.py \
  --state-dir "$VBT_UC_STATE" \
  --source /Volumes/Lenovo/VirtualBiotech/platform/artifacts/uc_independent_20261025 \
  --author "实际导入记录人"
```

须先有对应的研发项目。此命令不下载研究数据，不启动分析，不生成科学审阅。相同内容和路径重复导入不追加事件；内容或绑定路径变化则追加新版本，保留旧版本。源文件变化必须形成新的版本化导入，不能改写封存输入。

原版栏转录封存报告记载的 bioRxiv v1 主张。本轮没有重新取得或核对正式 Science 版本，不能把来源匹配称为正式版复现。五个 OSMR 队列从既有重建表复制分析单位、n／R／NR、探针、检验及终点规则等字段；其余条目不自动猜测这些字段，页面明确提示需读关联来源。`primary` 等源规则名仍是来源字段，不等于已恢复原作者临床终点选择。

## 页面与审阅

`/programs?id=osmr-uc-independent#scientific-review` 展示逐项差异、原始记录状态、来源链接、全部审阅历史及八类风险。每个风险可引用支持／反证、当前结果和具体差异。每次提交需要实际记录人、判断理由、适用范围、缺失／分歧、优先级、下一项验证及成功／停止条件。

审阅不覆盖原始比较字段，也不修改证据审阅、验证计划、结果或研发决定。本地署名不认证身份、领域资格或独立性；没有实际参与者时保持待审阅。不同意见并存，不以最后录入抹掉历史。

审阅绑定项目／假说／证据／结果／资产／导入版本的摘要哈希。新的审阅本身不会使此前同一范围审阅失效；相关来源或项目范围变化会显示需重审。绑定文件丢失或变化时仍可看历史与导出，但阻止提交当前比较范围审阅。引用附件的原始哈希也需要匹配。

## 导出与 AI 上下文

- `/program/comparison-report?id=PROJECT&format=md`：逐项对照、口径、来源和审阅历史。
- `/program/comparison-report?id=PROJECT&format=csv`：机器可读原始列、来源定位、结构化口径、完整性、审阅状态与历史。CSV 对以公式前缀开头的文本加保护字符；精确原始值保留在项目事件中。
- `/program/comparison-source?id=PROJECT&file=NAME`：只读已绑定且哈希一致的来源文件，不能传任意路径；返回 sandbox CSP。
- 原有完整 JSON 决策包保留全部导入版本、旧审阅和追加历史。

AI packet 升为 schema v3，增加逐项比较内容、比较版本与审阅摘要，省略署名和本机路径；自由文本仍可能包含使用者自行填入的敏感内容，导出不等于外发。审阅更新使旧 AI 草案显示过期，但历史回执不被改写。schema v1/v2 草案不会自动重标为 v3，也不把旧草案重新录入冒称新的推理。

## 实际 UC 验收与剩余工作

独立本地状态从既有 UC 程序库一致性备份产生，原服务继续运行。18 行对照导出的原始列与封存 CSV 逐字段相同，18 个绑定来源均通过实际 HTTP 读取与哈希核对。五行有重建表结构化口径；18 项仍待科学审阅，八类风险未生成实际审阅记录。三条原研究证据保持 pending，没有新建实验、实验结果或决定。

预览使用独立本地目录和端口 18767，尚无自动重启配置，也未部署生产。原作者病例脚本、TAURUS 结局／人群选择、健康对照分析集及部分来源版本仍需资料支持。Issue #28 保持打开；软件通过不能替代这些资料和实际独立审阅。

工程验证：工作台全量 1703 项通过、1 项跳过（74.96 秒）；跳过项依赖未随仓库分发的原始公司披露材料，不使用下载回退。七文件定向复验 127 项通过，覆盖来源变更／缺失、恶意路径、重复导入、审阅分歧、假说修订、引用校验、CSRF、HTTP 导出与脚本注入。均为工程测试，不是独立科学审阅。

后续集成复核补齐逐项差异内容进入 AI 上下文，并允许草案引用 `difference:条目编号`；来源不可用时不接受新的差异引用。当前 Codex 会话据含 18 项对照的 v3 上下文生成一份新的八类风险／五任务草案，并实际重跑两类既有只读工具，回执成功但仍待科学审阅。这是助手会话草案，尚非产品内模型调用或独立科学审阅。
